# Сайт «Двигатели и КПП в наличии»

Статический сайт-каталог по прайсам поставщика (выгрузка avtodik.ru). Никакого сервера и базы:
`build.py` превращает .xls в один файл `data/parts.json`, страница ищет по нему прямо в браузере.
Фото не копируются — подтягиваются с сервера поставщика по ссылкам.

Сейчас в каталоге: **1 199 позиций**, 46 марок — только агрегаты в сборе:
двигатели (656), АКПП вместе с вариаторами и роботами (384), МКПП (95), раздаточные коробки (64).

Навесное (генераторы, стартеры, ЭБУ, форсунки, компрессоры) отфильтровано списком `ONLY_CATS`
в `build.py` — чтобы вернуть весь моторный прайс на 5 337 позиций, поставьте `ONLY_CATS = None`.

Кузовной прайс (13 657 позиций) лежит в `prices/`, но на сайт не попадает: в `build.py` стоит
`ONLY_GROUPS = {"engine"}`. Чтобы вернуть кузов и салон — `ONLY_GROUPS = {"engine", "body"}`
и пересобрать. Селектор разделов в фильтрах тогда тоже надо вернуть в `index.html`.

## Что где

| Файл | Зачем |
|---|---|
| `config.js` | **телефон, WhatsApp, Telegram, название, город** — правьте здесь |
| `prices/` | прайсы поставщика (.xls) |
| `build.py` / `update.sh` | сборка `data/parts.json` из прайсов |
| `index.html`, `app.js`, `styles.css` | сам сайт |
| `data/parts.json` | готовый каталог (0,5 МБ) |

## Обновить наличие

1. Скачать свежие прайсы у поставщика.
2. Удалить старые из `prices/`, положить новые.
3. Запустить:

```bash
cd "/Users/drew/ВСЕ ДЕЛА/zapchasti-site" && ./update.sh
```

4. Поменять дату в `config.js` (`updated`) и залить папку на хостинг.

Раздел (кузов/двигатели) определяется автоматически по ссылкам на фото, так что порядок файлов не важен —
кузовной прайс просто пропустится с пометкой в выводе.

## Как работает поиск

- Слова ищутся по названию, марке, модели, кузову, двигателю, году и номерам — порядок не важен
  («mazda 3 lf-ve» и «lf-ve mazda 3» дают одно и то же).
- Строка, похожая на артикул (от 5 символов), ищется по номерам без учёта пробелов и дефисов:
  `8K0919051P`, `8k0 919 051 p` и `8K0-919-051-P` найдут одно и то же.
- Фильтры и поиск сохраняются в адресе страницы — ссылку на подборку можно отправить клиенту.

## Что стоит доделать позже

- Свои фото на популярные позиции: сейчас всё грузится с сервера поставщика, если он ляжет — картинок не будет.
- Пробег и видео работы двигателя: у части позиций это есть в описании, но отдельным полем не вынесено.
- Страницы под каждую позицию (отдельные URL) — нужно для индексации в Яндексе и Google.
- Формы заявки с отправкой на почту/в Telegram — сейчас связь только по кнопкам «Позвонить»/«WhatsApp».
