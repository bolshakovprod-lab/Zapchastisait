# Сайт «Двигатели и КПП в наличии» — Екатеринбург

Статический сайт-каталог контрактных агрегатов. Ни сервера, ни базы: скрипты превращают
прайс поставщика в готовые HTML-страницы, GitHub раздаёт их как сайт.

**Адрес:** https://dvigatel-ekb.ru/
**Репозиторий:** https://github.com/bolshakovprod-lab/Zapchastisait

Сейчас в каталоге **1 182 позиции**: двигатели, АКПП (с вариаторами и роботами), МКПП,
раздаточные коробки. Навесное оборудование и кузовные детали не публикуются.

## Обновить наличие

Положить свежий прайс `.xls` в `prices/` (старый удалить) и запустить:

```bash
./update.sh
```

Скрипт сам: пересоберёт каталог → скачает фото новых позиций → обработает их →
пересоберёт страницы для поисковиков → зальёт всё на GitHub. Занимает от пары минут
(если позиций мало) до получаса (если прайс сменился целиком).

## Что где лежит

| Файл | Зачем |
|---|---|
| `build.py` | прайс `.xls` → `data/parts.json` + `articles.csv`. Здесь же цены и фильтры |
| `describe.py` | свои описания, артикулы, синонимы для поиска |
| `download_photos.py` | качает фото поставщика в `photos/orig` |
| `process_photos.py` | обрезка, поворот, водяной знак → `photos/big` и `photos/thumb` |
| `photo_tools.py` | настройки обработки фото: обрезка, поворот, знак |
| `seo_build.py` | страницы товаров, категорий, марок, sitemap, robots, 404 |
| `seo_lib.py` | ЧПУ-адреса и шаблоны заголовков |
| `config.js` | **телефон, город, реквизиты, тексты преимуществ** — правится руками |
| `index.html`, `app.js`, `styles.css` | каталог с живым поиском |
| `privacy.html`, `terms.html` | политика по 152-ФЗ и условия продажи |
| `push_photos.py` | заливка фото частями (одним куском GitHub обрывает) |

Не в репозитории (см. `.gitignore`): `prices/` — прайсы поставщика, `articles.csv` —
таблица «наш артикул → артикул поставщика → закуп → цена → маржа», `supplier.py` —
адрес фотоархива поставщика, `photos/orig` — исходники фото, `venv/`.

## Правила, по которым считаются цены

В `build.py`:

```python
MARKUP = 1.33        # наценка
MIN_MARGIN = 14000   # но не меньше этой суммы с позиции
MIN_BUY = 5000       # дешевле такого закупа не публикуем
ROUND_TO = 500       # округление цены вверх
```

Цена = максимум из «закуп × 1.33» и «закуп + 14 000», округлённый вверх до 500 ₽.

## Что настроено для поисковиков

1 182 страницы товаров с ЧПУ-адресами и микроразметкой Product, 144 страницы категорий
и марок, sitemap.xml, robots.txt, канониклы, Open Graph, хлебные крошки, страница 404,
перелинковка главная → категории → марки → товар → похожие.

Каталог на главной рисует JavaScript — он для людей. Для поисковиков служат
статические страницы в `p/`, `k/`, `m/`.

## Что сделано, чтобы не было видно поставщика

Свои фото (обрезка, поворот, водяной знак), свои описания вместо текстов из прайса,
свои артикулы `ДК-XXXXXX`, наценка. Адрес поставщика вынесен в `supplier.py` вне репозитория.

Полностью скрыть не выйдет: на многих агрегатах складской номер написан краской прямо
на корпусе.

## Незакрытые вопросы

- Реквизиты продавца в `config.js` — стоят прочерки вместо ИНН, ОГРНИП, адреса и почты
- Яндекс.Вебмастер, Метрика, Google Search Console — сайт им ещё не скормлен
- Репозиторий публичный: `data/parts.json` с ценами скачивается любым желающим.
  Закрыть можно переездом на Cloudflare Pages — там приватный репозиторий бесплатен
