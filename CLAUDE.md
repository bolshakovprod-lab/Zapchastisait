## Как всё устроено

Прайс поставщика (.xls, выгрузка avtodik.ru) → `build.py` → `data/parts.json` →
`seo_build.py` → 1 678 статических страниц. Фото скачиваются у поставщика,
обрабатываются (обрезка, поворот, водяной знак) и хранятся свои.

Обновление наличия — одна команда `./update.sh`: каталог, фото новых позиций,
обработка, страницы, заливка.

| Файл | Зачем |
|---|---|
| `build.py` | прайс → каталог. Здесь цены, фильтры категорий, синонимы |
| `describe.py` | свои описания, артикулы ДК-XXXXXX, разбор марок и моделей |
| `seo_build.py` | страницы товаров, категорий, марок, моделей, sitemap |
| `photo_tools.py` | параметры обработки фото: обрезка, поворот, знак |
| `banners2.py` | рекламные баннеры из коллажа фото каталога |
| `export_ads.py` | папка с креативами и текстами на рабочий стол |
| `make_plan_pdf.py` | рекламный план в PDF |
| `config.js` | телефон, город, реквизиты, тексты преимуществ — правится руками |

Вне репозитория (в `.gitignore`): `prices/` — прайсы, `articles.csv` — таблица
«наш артикул → артикул поставщика → закуп → цена → маржа», `supplier.py` — адрес
фотоархива поставщика, `photos/orig` и `photos/avito`, `venv/`, `fonts/` в репозитории.

## Ценообразование

```python
MARKUP = 1.33            # наценка
MIN_MARGIN_LOW = 14000   # минимум с дешёвой позиции
MIN_MARGIN_HIGH = 17500  # минимум с дорогой (растёт линейно от 5 до 50 тыс закупа)
MIN_BUY = 5000           # дешевле не публикуем
ROUND_TO = 500           # округление вверх
```

Цена = максимум из «закуп × 1,33» и «закуп + минимум», округлённая вверх.
Медианная маржа 23 500 ₽, средняя наценка по каталогу 37 %.

## Решения владельца (не выводятся из кода)

- Публикуем только агрегаты в сборе: ДВС, АКПП с вариаторами и роботами, МКПП,
  раздатки. Навесное (ЭБУ, генераторы, форсунки) отфильтровано списком `ONLY_CATS`.
  Кузовной прайс на 13 657 позиций не публикуется вовсе.
- Срок гарантии в открытых текстах **не писать**. Только «гарантия на проверку
  и установку». Реальный срок — 14 дней, он для переписки, не для сайта.
- Доставка бесплатная **до транспортной компании**, не до СТО.
- Фото **не зеркалить** — патрубки и разъёмы должны быть на своих местах.
- Банковские реквизиты на сайт не выносить: закон не требует, а в открытом виде
  их используют для поддельных счетов.
- Продвижение: Авито Реклама (ADS) первым, Яндекс.Директ вторым. Массовая выгрузка
  карточек на Авито не нужна — фид `avito_feed.py` лежит про запас.

## Ловушки окружения

- **Chrome headless не работает** — ни скриншоты, ни печать в PDF. Для PDF —
  reportlab (`make_plan_pdf.py`), для проверки вёрстки — Browser pane.
- **В системных Arial и Menlo нет символа рубля.** Для картинок и PDF брать
  шрифты из `fonts/` (IBM Plex, Oswald).
- **Заливка фото только частями** — `push_photos.py`. Одним куском GitHub рвёт
  соединение на 680 МБ.
- Панель предпросмотра иногда отдаёт пустые скриншоты после прокрутки — проверять
  вёрстку измерениями через javascript_tool.
- Локальный сервер для проверки: `python3 -m http.server 8787` из папки проекта.
